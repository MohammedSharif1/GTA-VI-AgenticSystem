# Attribution & Credit Standards

## 1. On-Screen Overlay

- **Duration:** Visible for the full duration of the video.
- **Format:**
  - Creator content: `Source: [Creator Name]`
  - Official content: `Source: Rockstar Games`
- **Safe Zone:** Located within top 12-15% margin or lower third safe zones, avoiding platform UI overlaps.
- **TikTok note:** If platform rules flag overlays as unwanted watermarks, use caption and pinned-comment credit only.

## 2. Caption Templates

### English
```text
Clip from [Creator / Channel] — [Link]. Credit to the creator.
Game: Grand Theft Auto VI by Rockstar Games.
Want a clip removed? Contact [removal-email@domain.com].
```

### Arabic (Modern Standard Arabic)
```text
المقطع من [اسم القناة أو صانع المحتوى] — [الرابط]. الفضل لصاحب المقطع.
اللعبة: Grand Theft Auto VI من Rockstar Games.
لطلب إزالة المقطع تواصل معنا: [removal-email@domain.com].
```

## 3. Pinned Comments
Where supported (YouTube, TikTok), pin a comment repeating the source link and creator credit.
